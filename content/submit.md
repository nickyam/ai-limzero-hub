## 如何新增 / 修正资源

本站资源统一维护在仓库 `data/resources.yaml`，**网站内不提供任何提交表单**。欢迎通过 GitHub Pull Request 贡献。

1. Fork 仓库，编辑 `data/resources.yaml`，按字段规范追加或修正条目；
2. 提交前本地运行 `python3 scripts/check_urls.py`，确认链接有效；
3. 发起 Pull Request，注明核验依据与日期；
4. 合并后由 GitHub Actions 自动构建并部署。

## 收录原则（硬性）

- 仅收录**官方原生免费资源**（免费额度 / 免费套餐 / 试用额度）；
- 不收录共享账号、接码、破解、绕过厂商限制等内容；
- 每个条目需标注核验状态与最近核验日期；
- 文案使用【免费额度 / 免费套餐 / 试用额度】，不使用「白嫖、薅羊毛」等表述。

> 所有链接均新开标签页跳转官方地址，本站不中转、不代理、不存储任何凭证。
